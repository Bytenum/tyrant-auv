# Tyrant Simulation

Software simulation environment for Tyrant AUV development.

Planned components include:

* 6-DOF vehicle dynamics
* virtual sensors
* sensor noise models
* thruster model
* 6x8 thruster allocation
* EKF development
* LMPC development
* closed-loop testing

The simulation environment should remain sufficiently independent from the physical hardware to allow algorithm development before full vehicle integration.

## Planned Stack

Python.
